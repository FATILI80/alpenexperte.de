# Routing-Lauf (BRouter)

1. BRouter-Server starten (siehe Anleitung im Chat), Port 17777.
2. Im Ordner routing/ ausführen: `python route.py`
3. Ergebnis: routing/ergebnis.json

Startpunkt und Ziele stehen in start.json und ziele.json. Die Ziele sind Richtwerte und müssen per Nominatim geprüft werden.
